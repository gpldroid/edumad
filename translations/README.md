# EDUMAD — Multilingual Editions

This branch prepares four complete translations of the Arabic reference manuscript:
- Spanish (es)
- French (fr)
- English (en)
- Russian (ru)

## Source of truth
The Arabic manuscript in `manuscript/` on branch `editorial/closure-audit-2026-11` is the translation source for this work. The source branch is not yet merged into `main`; this translation branch is intentionally based on that reviewed editorial branch so no approved editorial changes are lost.

## Translation units
Each edition must contain the introduction, all 22 chapters, and the conclusion. No chapter may be summarized, silently shortened, or omitted. Chapter headings, section hierarchy, examples, tables, footnotes, citations, and bibliography entries must be preserved.

## Quality gates
1. Terminology consistency against the shared glossary.
2. Legal accuracy: distinguish slavery, enslavement, forced labour, trafficking in persons, debt bondage, servitude, and exploitation.
3. Preserve all source claims, caveats, dates, statistical scopes, and causal limitations.
4. Preserve source bibliographic records. Translate explanatory annotations, not publication titles or official institutional names.
5. Native-language copy-editing for fluency without changing the author's argument.
6. Independent bilingual review for each complete edition.
7. Build and inspect a separate PDF for each language before release.

Machine-assisted translation may be used as a first draft only. It is not an approved final translation.
