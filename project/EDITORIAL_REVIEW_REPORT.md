**النطاق:** فحص بنية المستودع والوثائق وقارئ HTML وعينات من نصوص الفصول.  
**الحالة:** تدقيق أولي؛ ليس مراجعة علمية نهائية أو تحكيماً أكاديمياً.

## 1. ما تم فحصه
- README وسجل التقدم وجرد الأرشيف والخاتمة.
- قارئ HTML: قائمة الملفات، ترتيب تحميل الفصول، رسالة الحالة، قسم المراجع، وآلية الطباعة.
- عينات من الفصلين 4 و5، والفصول 16 و17 و18، والخاتمة.
- بنية العناوين والتنبيهات التحريرية في النصوص التي تمت معاينتها.

## 2. نتائج إيجابية
- المخطوط يميز في عدة مواضع بين الرق القانوني والعمل الجبري والاتجار بالبشر وبين الهيمنة والتبعية الاقتصادية؛ وهذا تمييز ضروري يجب الحفاظ عليه.
- الفصول 4 و5 تحمل تنبيهات صريحة بأنها إعادة بناء تحريرية، والفصل 5 يوضح أن المسودة الجزئية السابقة يجب دمجها عند العثور عليها.
- الفصلان 16 و17 يعالجان موضوعات الأسرة والجسد والصحة والزمن، والفصل 18 يتناول التعليم والمعرفة والفرص، بما يدعم اتساع النطاق الموضوعي.
- قارئ HTML يحمّل ملفات الفصول من مسارات Raw GitHub ويضع الخاتمة في قسم مستقل.
- يوجد تنبيه ظاهر بأن المراجع والفهارس لم تصبح نهائية.

## 3. ملاحظات يجب معالجتها قبل النشر

### أ. ضبط حالة المخطوط
كانت بعض الوثائق تسجل أن الفصول 19–22 والخاتمة لم تُكتب، رغم وجود ملفاتها. يجب اعتماد الوصف الموحد التالي في كل الوثائق:
- المقدمة والفصول 1–15 و19–22: إعادة بناء تحريرية جديدة.
- الفصول 16–18: مسودات محفوظة متفاوتة الاكتمال وتحتاج المراجعة.
- الخاتمة العامة: نص تركيبي جديد.
- لا يوجد حتى الآن إصدار نهائي معتمد.

### ب. الفهرس والعناوين
- عنوان الفصل 1 مؤقت، والفصل 3 يحمل عنواناً وظيفياً مؤقتاً.
- عناوين بعض الفصول 4–15 و19–22 أُنشئت لإكمال البناء وتحتاج المطابقة مع الفهرس المرجعي.
- يجب فحص تطابق عنوان كل فصل مع الباب والمباحث الواردة في `APPROVED_TABLE_OF_CONTENTS.md` قبل اعتماد النسخة النهائية.

### ج. التوثيق
- قوائم المراجع الأولية لا تكفي وحدها لإثبات الادعاءات.
- يلزم إنشاء نظام إحالات موحد: نمط ببليوغرافي واحد، بيانات كاملة، روابط/معرّفات DOI أو ISBN عند توفرها، وأرقام صفحات للاقتباسات المباشرة.
- يجب التحقق من كل رقم إحصائي وتاريخه ونطاقه الجغرافي وتعريف المؤشر، خصوصاً الإحصاءات الواردة في موضوع الرعاية والعمل والصحة.
- يجب فصل الرأي التحليلي عن الادعاء التجريبي، وإسناد الأخير إلى مصدر يمكن التحقق منه.

### د. التماسك والتكرار
- هناك تقاطع موضوعي طبيعي بين فصول الاقتصاد والديون والاستهلاك والعمل، وبين فصول السلطة والإعلام والوعي، وبين فصول التقنية والبيانات والمنصات.
- يلزم إعداد مصفوفة للمفاهيم والحجج لتحديد وظيفة كل فصل ومنع تكرار التمهيدات والخلاصات.
- توحيد استعمال مصطلحات: العبودية المعاصرة، الرق، العمل الجبري، الاتجار بالبشر، الاستغلال، الهيمنة، التبعية، والإكراه.

### هـ. قارئ HTML
- قائمة الفصول تعرض عناوين مؤقتة لبعض الفصول؛ ينبغي أن تطابق عناوينها النهائية بعد تثبيت الفهرس.
- آلية التحميل الحالية تسلسل طلبات الفصول واحداً تلو الآخر؛ يمكن تحسين الأداء بتحميل متوازٍ بعد اختبار معالجة الأخطاء وترتيب العرض.
- يجب اختبار جميع الروابط ومعاينة الطباعة/حفظ PDF على الهاتف وسطح المكتب.
- صفحة القراءة لا ينبغي أن تعرض حالة «نهائي» قبل اجتياز المراجعة واعتماد المؤلف.

### و. GitHub Pages
- وجود ملف workflow لا يثبت أن Pages منشور فعلاً.
- يلزم التحقق من إعداد Source = GitHub Actions ومن أحدث تشغيل، ثم اختبار الرابط العام بعد نجاح التشغيل.

## 4. ما لم يُنجز في هذا التدقيق
- لم تتم مراجعة كل فقرة في الفصول الـ22 سطراً بسطر.
- لم يتم التحقق الخارجي من كل مرجع أو اقتباس أو رقم إحصائي.
- لم تتم مقارنة النصوص المعاد بناؤها بالنصوص الأصلية الكاملة؛ لأن بعض النصوص الأصلية غير متاحة في الملفات المفحوصة.
- لم يُنتج PDF نهائي، ولم يتم اعتماد عدد صفحات نهائي.

## 5. ترتيب العمل التحريري المقترح
1. تثبيت الفهرس والعناوين، وإعداد جدول ربط بين العناوين المرجعية وأسماء الملفات.
2. إعداد قائمة مصادر موحدة، ثم تدقيق الادعاءات والإحصاءات والاقتباسات في كل فصل.
3. مراجعة الفصول 16–18 أولاً باعتبارها مسودات محفوظة، مع عدم محو نصوصها.
4. مراجعة الفصول المعاد بناؤها على دفعات، مع سجل تعديلات لكل فصل.
5. مراجعة الاتساق والتكرار والانتقالات بين الأبواب.
6. مراجعة المقدمة والخاتمة بعد استقرار متن الكتاب.
7. اختبار قارئ HTML وGitHub Pages، ثم إعداد PDF تجريبي قبل النسخة النهائية.

المخطوط يمتلك هيكلاً ومواد قابلة للتطوير، لكنه لا يستوفي حالياً شروط الإصدار النهائي الموثق. يجب عدم وصفه بأنه كتاب أكاديمي مكتمل أو جاهز للبيع/النشر قبل إغلاق الملاحظات أعلاه واعتماد المؤلف.
