## 4. قرار الانتقال إلى التصميم

يمكن بدء مرحلة تصميم الغلاف والهوية البصرية ونموذج صفحات الكتاب بالتوازي مع بوابات المراجعة البشرية أعلاه، بشرط:
- وسم أي نموذج تصميم بأنه **تصور أولي** وليس غلاف إصدار نهائي.
- عدم تثبيت عدد صفحات أو كعب الغلاف حتى اعتماد مقاس الكتاب وملف PDF النهائي.
- عدم وضع ISBN أو شعار ناشر أو بيانات نشر غير صادرة فعلياً.
- اعتماد اسم المؤلف كما حدده: **عماد لمراني**.
- عدم تغيير متن الكتاب أثناء التصميم إلا عبر PR منفصل موثق.
