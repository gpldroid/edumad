# قائمة ضبط الجودة قبل الإصدار النهائي

**الحالة:** قائمة تنفيذ مفتوحة. لا يصدر PDF نهائي أو وسم إصدار 1.0.0 قبل اعتماد المؤلف واجتياز جميع البوابات الحرجة.

## 1. المحتوى والمصادر
- [ ] تثبيت عنوان الكتاب والفهرس النهائي وعناوين الفصول المؤقتة.
- [ ] مراجعة كل ادعاء تاريخي وقانوني وصحي واقتصادي وتقني بمصدر أولي أو موثوق.
- [ ] التحقق من كل رقم: سنة القياس والنشر والوحدة والمقام والنطاق والمنهج والقيود.
- [ ] مراجعة الاقتباسات حرفياً وتحديد الطبعة والصفحة والترجمة.
- [ ] التحقق من DOI وISBN والروابط وبيانات المؤلف والناشر.
- [ ] فصل التشريعات والمعاهدات عن المراجع الأكاديمية وفق سياسة التوثيق.
- [ ] تطبيق `TERMINOLOGY_GLOSSARY.md` على الفصول الـ22.
- [ ] التأكد من عدم وصف أي مثال افتراضي بأنه دراسة ميدانية.
- [ ] فصل المخرجات والنتائج والأثر السببي في تقييم البرامج.

## 2. التحرير والاتساق
- [ ] مراجعة لغوية عربية كاملة للفصول والمقدمة والخاتمة.
- [ ] توحيد المصطلحات والتعريفات والتهجئة وعلامات الترقيم.
- [ ] فحص التكرار بين الفصول وتحديد وظيفة كل فصل.
- [ ] مراجعة الانتقالات بين الأبواب والفصول.
- [ ] التأكد من أن الخاتمة لا تدعي نتائج لم تثبتها الأدلة.
- [ ] مراجعة لغة الحديث عن الضحايا والمهاجرين والفئات الهشة وتجنب الوصم.
- [ ] مراجعة الجداول والعناوين والتعليقات والملاحظات.

## 3. التحكيم والاعتماد
- [ ] دعوة مراجعين خارجيين مستقلين وفق `EXTERNAL_PEER_REVIEW_BRIEF.md`.
- [ ] جمع تقارير المراجعين وحفظ إفصاحات تضارب المصالح.
- [ ] إنشاء سجل استجابة مفصل لكل ملاحظة.
- [ ] إغلاق الملاحظات الحرجة والكبيرة أو توثيق قرار المؤلف بشأنها.
- [ ] اعتماد المؤلف للنسخة النصية النهائية وحقوق النشر وبيانات الإصدار.

## 4. قارئ HTML والموقع
- [ ] اختبار روابط الفصول والمراجع والتنقل.
- [ ] اختبار العرض على الهاتف واللوحي والحاسوب.
- [ ] اختبار البحث والتنقل وإمكانية الوصول ولوحة المفاتيح.
- [ ] اختبار تحميل الفصول ورسائل الحالة والروابط البديلة.
- [ ] اختبار الطباعة وحفظ PDF من المتصفح.
- [ ] منع ظهور شارات «نهائي» أو «محكّم» قبل الاعتماد.

## 5. PDF والتنضيد
- [ ] تثبيت مقاس الصفحة والهوامش والخطوط العربية واتجاه RTL.
- [ ] التأكد من عدم تقطيع العناوين والجداول والهوامش.
- [ ] مراجعة ترقيم الصفحات والفهرس والإحالات الداخلية.
- [ ] إنشاء PDF تجريبي بعد إغلاق التحرير.
- [ ] فحص PDF بصرياً على الهاتف والحاسوب والطباعة.
- [ ] إنتاج PDF نهائي من المصدر المعتمد وحساب عدد الصفحات الفعلي.
- [ ] حفظ نسخة مصدرية قابلة لإعادة الإنتاج.

## 6. الإصدار والنشر
- [ ] تحديث CHANGELOG وREADME وPROGRESS.
- [ ] تحديث رقم الإصدار وفق RELEASE_POLICY.
- [ ] تشغيل المدقق البنيوي وجميع الاختبارات.
- [ ] فحص الروابط الداخلية والخارجية.
- [ ] التحقق من GitHub Pages بعد النشر الفعلي.
- [ ] مراجعة PR والتغييرات كاملة.
- [ ] اعتماد المؤلف قبل الدمج أو إنشاء tag.
