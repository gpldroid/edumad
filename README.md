# العبودية المعاصرة

**المؤلف:** عماد لمراني

مستودع أرشفة وتأليف كتاب «العبودية المعاصرة»، تمهيداً للمراجعة العلمية والتحرير النهائي وإنتاج نسخة PDF احترافية ثم إدراجه ضمن مشروع EduBooks.

## حالة المشروع

- الحجم المستهدف: 550 صفحة.
- البنية المعتمدة: 8 أبواب و22 فصلاً.
- الفهرس المرجعي النهائي معتمد في المحادثة.
- يجري استكمال التأليف على مراحل، ثم مراجعة جميع الفصول وتوحيد التوثيق.
- لا تُعد المسودات المودعة هنا نسخة نهائية جاهزة للنشر.

## تنظيم الملفات

- `manuscript/chapters/`: نصوص الفصول المحفوظة.
- `project/PROGRESS.md`: سجل التقدم والمواد التي يلزم استعادتها.
- `project/EDITORIAL_NOTES.md`: قواعد التحرير والتوثيق والنشر.

## تنبيه حول اكتمال الأرشيف

المستودع كان فارغاً عند بدء عملية الحفظ. أُودعت فيه النصوص الكاملة للفصلين 16 و17 المتاحة في سياق المحادثة الحالية، إضافة إلى سجل المشروع. لا يتضمن هذا الإيداع نصوص الفصول السابقة كاملة؛ يجب استعادتها من المحادثات/المسودات الأصلية قبل الادعاء بأن جميع صفحات الكتاب محفوظة في المستودع.
