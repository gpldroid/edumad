# العبودية المعاصرة

**المؤلف:** عماد لمراني

مستودع تأليف ونشر كتاب «العبودية المعاصرة»، وهو مشروع بحثي نقدي في آليات السيطرة الحديثة وشروط الحرية والكرامة الإنسانية.

## خطة الإصدار
- الحجم المستهدف: نحو 400 صفحة في الإخراج الطباعي النهائي؛ ويُحسم العدد الفعلي بعد التنسيق.
- البنية: مقدمة عامة، 8 أبواب، 22 فصلاً، خاتمة، مراجع وفهارس.
- اللغة: العربية.
- المؤلف: عماد لمراني.

## القراءة والنشر
- [قراءة المخطوط عبر GitHub Pages](https://gpldroid.github.io/edumad/)
- [صفحة المستودع](https://github.com/gpldroid/edumad)
- index.html: قارئ عربي متجاوب مع فهرس وتنقل وطباعة/حفظ PDF.
- .github/workflows/pages.yml: نشر تلقائي عند تحديث main أو تشغيل سير العمل يدوياً.

## حالة المخطوط
تتضمن الأرشفة الحالية نصوص الفصلين 16 و17 ومسودة الفصل 18. ولا تزال نصوص المقدمة والفصول 1–15 والفصول 19–22 والخاتمة بحاجة إلى استعادة أو تأليف ومراجعة. لذلك لا يمثل الموقع بعد نسخة مكتملة من الكتاب.

## تنظيم الملفات
- manuscript/chapters/: نصوص الفصول.
- project/APPROVED_TABLE_OF_CONTENTS.md: الفهرس المستعاد.
- project/ARCHIVE_INVENTORY.md: جرد المواد المتاحة.
- project/EDITORIAL_NOTES.md: قواعد التحرير والتوثيق.
- project/PROGRESS.md: سجل التقدم.

## منهجية التحرير والتوثيق
1. الحفاظ على النصوص الأصلية المتاحة وعدم اختلاق نصوص مفقودة.
2. استكمال الفصول وفق الفهرس المعتمد.
3. التمييز بين العبودية القانونية التاريخية وأشكال الهيمنة والتبعية المعاصرة.
4. دعم الادعاءات الواقعية والإحصائية بمصادر أصلية.
5. التحقق من بيانات المراجع والطبعات والصفحات.
6. مراجعة علمية ومنهجية ولغوية قبل النشر.
